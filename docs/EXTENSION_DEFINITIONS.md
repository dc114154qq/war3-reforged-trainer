# 战役／地图背包定义处理

按钮位于“3.0 扩展”的“读取扩展状态”下方。此功能离线处理 `.w3n`、`.w3x`，也接受独立 `.w3m`。无需连接游戏。

文件原件保留；每次运行生成独立结果目录，其中包含处理副本、`处理报告.json` 和 `处理日志.jsonl`。路径支持完整选中复制，界面提供“复制输出路径”和“打开输出文件夹”。

## 处理规则

- 以 3.0.1.24360 的对象定义补齐背包、装备、天赋及其递归依赖。
- 优先保留地图自己的数据表，再使用战役共有表；缺少表时按新版本游戏的地图数据选择规则使用对应基线。
- 只加入缺失记录、文字字段和界面资料，不覆盖已有记录及地图自定义对象。
- 保留战役中每个章节的原有压缩／加密／单块／CRC 标志。写入后重新打开全部归档，比较原有成员、修改成员和新增定义。
- 同编号冲突、信息格式未适配、章节缺失或校验失败时停止，不发布半成品文件。签名归档需单独处理。
- 旧存档不自动迁移；文件校验不等同于游戏效果验收。

资料包是严格静态数据，运行时不下载内容、不执行地图脚本。资料来源构建与每个表的摘要写在包内 `manifest.json`。用于处理 MPQ 的 StormLib DLL 校验固定 SHA-256，许可证随 EXE 提供。

## 本地构建

使用当前 `tools/build_release_2110.py` 和 `War3ReforgedTrainer-2.1.10.spec`。旧构建产物与旧发布清单保留。缺少 MPQ 依赖时先运行 `python tools/prepare_mpq_dependency.py`；构建器也会执行相同准备与哈希验证。
