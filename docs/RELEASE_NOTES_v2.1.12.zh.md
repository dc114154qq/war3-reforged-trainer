# 魔兽 3.0 修改器 2.1.12

本次为 **魔兽争霸 III 3.0.1.24371** 加入专门适配，已直接放进 EXE，下载后即可使用，无需另装适配文件。网站归入魔兽 3.0 分区。

## 本次更新

- 更新新游戏版本的单位读取、玩家与选中单位列表、技能调用所需的基础数据，并补上本版攻速查询所需的位置。
- 合并此前本地预览的 **Ctrl+X 鼠标传送精度修复**，改善斜坡等地形的落点计算。实际游戏中的落点仍需使用时核对。
- 修正自动定位中一处过早确认对象身份的问题；构建时检查每份游戏配置都有对应的定位依据，减少更新时漏打包数据的情况。
- 保留批量修改、背包定义补齐、全被动／全光环逐项跳过等现有功能。原有六份游戏配置保留。

## 当前限制

在 **3.0.1.24371** 下，**3.0 详细属性、迷雾操作、备用本地玩家模式**所需数据尚未核对完整，暂未启用。技能升级保留原有错误处理，没有套用旧版本的异常恢复位置。

本次是 24371 的专门适配；后续未知版本的自动适配仍有缺口，暂不承诺更新游戏后所有功能都会自动适用。

## 验证范围

已在当前游戏完成只读核对：28 个玩家、选中英雄及另一个单位、19 个组件、1,857 项游戏接口；相机、护甲、智力和攻速查询及清理通过。没有试改游戏数据。

离线回归分批合计 **5,013 项独立测试、120 个子测试通过，29 项跳过**。完整进程中出现的一项 Tk 界面初始化错误，原用例已在独立进程通过；并非一次全量运行零错误。EXE 包内数据和启动自检通过。实际修改效果、Ctrl+X 实际落点和外机运行尚未验收。

内置配置：3.0.0.24268、3.0.1.24323、3.0.1.24332、3.0.1.24342、3.0.1.24360、3.0.1.24365、3.0.1.24371。不同构建的可用功能以各自配置为准。
