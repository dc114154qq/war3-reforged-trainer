# 魔兽 3.0 修改器 2.1.13

补齐 3.0.1.24371 的详细属性、迷雾操作和备用玩家索引，并更新技能升级的异常恢复判断。适配直接放在 EXE 内。

- 恢复“3.0 详细属性”，区分固定数值和百分比所需的四类技能数据已分别核对。
- 补齐迷雾查询、开关的六处恢复位置。新版使用 4 字节读取指令，旧桥接只认 5 字节；现在按实际指令长度恢复，仍严格核对位置、异常和读取地址。
- 从游戏自己的模式分支补齐备用玩家索引；保留普通模式的快速读取。
- 技能升级的尾部读取换了寄存器，补上新指令核对；仍须实际等级读回一致才接受。
- 自动定位加入上述恢复位置和玩家模式的识别；只查询迷雾时，不再要求无关的修改入口也已定位。完整未知版本自动适配仍取决于公共对象和状态解码的确认。
- 修复最近两次更新导致自动连接卡住的状态解码：沿实际跳转追踪完整算式，分别恢复 24365、24371 的计算；隐藏 24371 的专门配置后，已在当前游戏从 24365 来源自动连接、读取单位并复用缓存。高级功能仍按各自已确认的数据开放；当游戏代码暂时缺少依据时，相关调用仍会被拦截，后续未知版本仍可能需要补充适配。

当前游戏的迷雾状态、详细属性、基础属性和相机只读查询已通过；实际 Windows 异常恢复、拒绝错误指令和错误位置的检查通过。本轮没有替用户修改游戏属性、切换迷雾或添加技能；实际写入效果、备用模式实机及外机运行仍需分别验收。

离线回归分批合计 5,052 项独立测试、120 个原生子测试通过，29 项跳过；七份配置的同快照性能比较、包内核对和 EXE 启动自检通过。详细记录见随附清单。
