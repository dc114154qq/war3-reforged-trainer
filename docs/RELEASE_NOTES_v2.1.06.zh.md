# 魔兽争霸3重制版修改器 2.1.06

本版本用于 **Warcraft III 3.0 系列**。本次主要完善官方背包的添加流程和问题日志，并增加对新游戏构建的自动识别。建议使用官方背包功能的用户更新。

## 这次改了什么

- **添加背包时会检查配套能力。** 针对“背包物品已经加上，但装备或天赋面板点不开”的反馈，修改器会检查背包、装备、对应英雄的天赋和面板打开能力，缺哪项就补哪项。加瑞克的背包也包含在内。每补一项都会检查游戏里的结果；中途出错会停止后续步骤。
- **背包操作的日志更完整。** 添加成功和失败都会留下记录，能看清当时的修改器版本、游戏版本、目标单位，以及哪一步成功、哪一步出错。再次反馈问题时，请附上日志目录里的 `backpack-*.log`。
- **增加新游戏构建的自动识别。** 遇到同系列、尚未单独适配的游戏构建时，修改器会尝试查找它需要的数据，确认后开放对应功能。已经单独适配的四个构建继续使用各自的配置。
- **补充装备和英雄技能列表。** 官方装备列表扩充到 325 项，新增六位英雄的 27 项技能记录。具体地图是否支持添加，仍取决于地图有没有加载对应数据。
- **修正 3.0.1.24332 的攻速组件读取配置。** 保留上一版的战役存档、英雄数据和 RPG 存档码提取功能。

## 游戏版本与使用说明

继续支持 Warcraft III **3.0.0.24268、3.0.1.24323、3.0.1.24332、3.0.1.24342**，连接时自动选择对应配置。

添加官方背包时，先选中目标英雄。如果经典物品栏第 1 格已有其他物品，先腾空该格；如果已放着对应背包，可以再次使用添加功能检查并补齐缺失能力。

新构建的自动识别仍有范围限制，部分装备、天赋、效果或开图相关功能的数据尚未确认。这些功能会给出提示，其他已确认的功能可以继续使用。自动识别不代表今后所有游戏更新都已完整适配。

## 验证情况

本次完整代码回归有 4,636 项测试和 120 项子测试通过，29 项跳过；四个已适配构建的路径与性能检查通过，安装包和离线启动自检通过。当前 3.0.1.24342 也完成了只读识别检查。

背包补齐逻辑已完成代码验证；此前反馈问题的外机，实际面板打开结果仍待该机使用新版确认。因此，本次发布未把该外机问题列为已实测解决。
