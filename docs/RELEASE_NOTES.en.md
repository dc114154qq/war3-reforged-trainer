# Warcraft III 3.0 Trainer 2.1.16

Player Resources now lets you edit the gold remaining in selected mines or all mines on the map. Results are shown per mine so you can check what changed.

1. **Selected mines**: select a gold mine in the game, open Player Resources, enter the target remaining gold and click Set Selected Mines. You can read the current amount first.
2. **All mines on the map**: read the map-wide list, then apply the target amount to every mine, including other players' and neutral mines.
3. **Clear results**: see each mine's position, previous amount, resulting amount and outcome. Elapsed time is displayed while processing. Individual failures are skipped and reported in a dialog; completed changes are kept.

Supports standard, entangled and haunted gold mines, plus custom mines with readable remaining resources. The range is **0–100000000**. **Setting 0 exhausts a mine.** Special scripted mining systems depend on the map's implementation.

**Run**: Warcraft III 3.0, Windows 10/11 x64. Launch the EXE directly; no Python, Node.js or separate frontend server is needed. The lightweight desktop uses Microsoft WebView2. If missing, first launch offers an Internet-based installation.

Retains item-effect editing, ability fields, loadout restoration, backpack-definition processing, custom artifact presets and existing features, with the same seven game adapter profiles.
