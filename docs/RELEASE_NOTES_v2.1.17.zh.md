# 魔兽 3.0 修改器 2.1.17

修正 Ctrl+X 瞬间移动、Ctrl+A 复制单位等功能的鼠标定位，并修复自定义背包的天赋读取、加点和添加天赋失败的问题。快捷键和操作方式保持不变。

1. **Ctrl+X 瞬间移动更准确**：修正传送位置偏离鼠标的问题，并处理视角、缩放和窗口宽高比对坐标的影响。

2. **Ctrl+A 复制单位同步修正**：复制到鼠标处的单位使用同一套新坐标换算；其他共用鼠标坐标的功能也同步受益。

3. **兼容自定义背包的天赋**：修复自定义背包读不到天赋、增加天赋点和添加所选天赋失败的问题。基于游戏原生天赋制作的自定义背包，会按当前地图的实际天赋层和选项处理。

本次修订已在自定义背包上验证天赋读取、增加 1 点和添加所选天赋，测试后还原。

测试版的 **Ctrl+X 和 Ctrl+A 已由用户实测确认准确**。特殊地图的碰撞、地图边界等游戏规则仍会影响最终位置。

**使用方式**：适用于魔兽 3.0，Windows 10/11 x64。直接打开 EXE，无需安装 Python、Node.js 或单独启动前端。沿用轻量 WebView2 桌面界面；缺少微软 WebView2 时，首次启动会提示联网安装。

保留金矿剩余金币、物品效果编辑、技能字段、套装恢复、背包定义补齐、自定义神器及其他已有功能，继续使用原有七份游戏适配配置。
