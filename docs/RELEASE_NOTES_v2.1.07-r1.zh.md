# 魔兽 3.0 修改器 2.1.07（日志增强构建）

软件版本保持 2.1.07，替换本版本的当前下载构建。这次主要把背包和技能日志写得更详细，方便确定失败发生在哪一步。

- 背包日志记录所选单位、背包物品、完整对象身份、六格经典物品栏，以及每个组件为什么保留、补齐或停止。
- 查询、添加、激活、删除技能和挂载背包物品能力时，逐次记录函数名称、实际参数、执行阶段、返回值和后续读回。异常调用会明确记录“进入了调用，但没有正常返回”。
- 记录当前游戏和修改器构建、桥模块哈希、实际使用的原生函数注册信息与地址。函数注册正常不再被误解成具体的 AIni 技能定义也已注册。
- 全屏季风和群星陨落记录每次施法、等待、状态观察、恢复原技能参数和清理结果；失败时保留原始错误及完整异常链。
- 同一次操作同时保存 `.log` 和 `.jsonl`，用相同操作编号和顺序号关联。结构化日志每条记录单独一行；发送原生操作前先保存执行边界，返回后保存结果。
- 成功和失败都留记录。每次原生操作最多记录 1,024 次调用，达到上限会写明遗漏数量，并保留最后一次调用；缺失信息不会被解释成已经成功。

日志增强观察原有调用，不额外试加技能、不试写游戏数据、不自动重放失败操作，也不采集游戏鼠标点击。

本轮按要求只做代码验证。完整回归通过 4,758 项测试和 120 项子测试，29 项跳过；专项回归、生产桥编译与适配依赖审计通过。已有背包和技能修复保留。四个已收录游戏构建的适配数据、自动定位规则及此前外机传输修复保留。

原外机日志确认了添加 AIni 被拒绝，但游戏内部拒绝的最终原因和修复后的外机效果仍未确认。这次日志增强不表示已经证明外机故障消除。

此版本属于魔兽 3.0 分区；历史版本和魔兽 2.0／社区版分区保留。
