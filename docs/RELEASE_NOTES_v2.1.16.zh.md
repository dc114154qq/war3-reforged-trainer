# 魔兽 3.0 修改器 2.1.16

“玩家资源”页新增金矿剩余金币修改：可以修改选中的金矿，也可以一次修改全图金矿；操作后逐座显示结果，方便确认哪些已经生效。

1. **修改选中的金矿**：在游戏中选中金矿，打开“玩家资源”，填写目标剩余金币，再点击“修改选中金矿”。也可以先读取，查看当前金额。
2. **批量修改全图金矿**：点击“读取全图金矿”查看列表，再点击“批量修改全图金矿”。每座金矿都会设成填写的目标值，包含其他玩家和中立金矿。
3. **结果看得清楚**：列表显示金矿位置、修改前后金币和逐项结果，处理时显示等待用时；个别矿点失败会跳过并弹窗说明，已经成功的修改会保留。

支持普通、缠绕和闹鬼金矿，以及能读取到剩余资源的自定义矿点。数值范围为 **0–100000000**；设为 **0 会耗尽金矿**。特殊自定义采矿系统的识别仍取决于地图的实现。

**使用方式**：适用于魔兽 3.0，Windows 10/11 x64。直接打开 EXE，无需安装 Python、Node.js 或单独启动前端。沿用轻量 WebView2 桌面界面；缺少微软 WebView2 时，首次启动会提示联网安装。

保留此前的物品效果编辑、技能字段、套装恢复、背包定义补齐、自定义神器及其他功能，继续使用原有七份游戏适配配置。
