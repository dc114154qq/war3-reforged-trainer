# 魔兽 3.0 修改器 2.1.15

新增装备加成和物品附带技能数值编辑，补充 ID 目录的效果说明；修复技能字段反复读取、套装恢复速度和部位、装备目录创建，以及部分战役补齐背包定义报错的问题。

1. **装备加成、物品技能可以修改了**：在“物品字段”中选择“装备加成 / 附带技能”，再选择物品位置、槽位和等级。修改针对当前这件物品，显示来源技能，写入前重新核对物品和原数值，避免旧列表改到别的物品。地图脚本另行计算的效果以游戏内为准。
2. **ID 目录补充详细说明**：物品、技能显示描述和基础效果数值，单位显示介绍；支持按效果搜索，长说明可以完整查看。资料来自游戏基础数据，自定义地图可能不同；缺少可核实资料的条目会明确提示。
3. **修复技能字段反复读取出错**：处理失效的旧技能记录，修正编辑等级后再次读取报错、列表空白的问题；读取失败时清除旧摘要，避免显示上一次的技能。
4. **套装恢复更快，穿戴部位更准确**：已在正确部位的同数量装备直接保留，恢复时先处理主副手，饰品按保存位置穿戴，临时卸下的装备也回到原槽。自动处理任意装备槽，显示等待时间并防止重复点击；特殊部位相互冲突时保留全部物品，提示手动完成剩余穿戴。
5. **修复 3.0 装备目录的创建按钮**：修正 eagt 等装备点击“创建”报错，使用与大象添加物品相同的入口；同时修正技能目录传递代码、等级的参数。
6. **补齐背包定义更兼容老战役**：兼容复制、改名对象保留旧结束标记的文件，保留战役原有自定义对象，补充具体文件、对象和字段位置的处理日志。六份战役、共 64 个章节完成文件处理和归档校验；本轮未逐章进游戏。此前处理失败的文件请用本版重新生成副本，并从副本的章节入口进入，旧存档保留原地图数据。
7. **修复部分地图添加天赋点无效**：直接给英雄现有天赋系统加点，已完成 +1 实机验证，无需为此重新补齐地图定义。

**运行方式**：适用于魔兽 3.0，Windows 10/11 x64。下载后直接打开 EXE，无需安装 Python、Node.js 或单独启动前端。沿用轻量 WebView2 桌面界面；缺少微软 WebView2 时，首次启动会提示联网安装。

保留 2.1.14 的新版界面、自定义并持久保存六件神器及其他已有功能，沿用七个已适配的游戏构建。
