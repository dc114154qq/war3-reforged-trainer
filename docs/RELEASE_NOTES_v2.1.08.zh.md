# 魔兽争霸3重制版修改器 2.1.08

本版基于个人网站当前的 2.1.07，适用于魔兽争霸 III 3.0 系列。

- 在“选中单位”旁新增“批量修改”栏目。
- 点击读取，列出游戏里选中的所有单位代码。同一种单位有多只时分别显示，可逐只勾选。
- 支持“全选”“全不选”，单击单位行也能选中或取消。
- 列出这些单位实际可修改的全部单位字段，每个字段都有目标值输入框。留空就保持原值。
- 批量修改时，某单位缺少字段、字段只读或修改失败，会记录原因并继续处理其他项目。
- 显示各项修改结果，详细过程同时写入文本日志和 JSONL 日志。
- 游戏进程或地图发生变化时停止旧批次，重新读取后再操作。

保留 2.1.07 的背包、技能、详细日志与全光环／全被动默认最高等级设置。

本轮采用离线代码、界面与打包验证；实际游戏效果未在本轮操作游戏验收。
