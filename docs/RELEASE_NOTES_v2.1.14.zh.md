# 魔兽 3.0 修改器 2.1.14

1. **UI 更新**：换用新版桌面界面，支持深色、浅色主题，重新整理功能页面。完善文字对比度、操作进度和错误弹窗，输出文件及日志路径可以完整查看和复制。
2. **一键神器支持自定义，且持久保存**：在 Ctrl+Num3 一键神器旁填写六件装备的代码。修改后自动保存，下次打开继续使用，也可一键恢复默认方案。
3. **修复大象操作后技能字段列表消失**：使用大象功能后，重新读取技能字段会刷新当前单位的数据，修复此前需要重启修改器才能恢复列表的问题。
4. **修复恢复套装后误删已装备物品**：已经放入正确装备槽的物品会保留。部分完成或后续检查异常时显示实际结果，避免把已经生成、装备好的物品再次取出删除。
5. **修复补齐背包定义失败**：修正老战役过滤新增背包定义、补齐后加载崩溃，以及背包已添加却误报持有者不匹配的问题。请用本版重新处理此前未生效的战役或地图，并从生成副本的章节入口进入；旧存档保留保存时的数据。

**运行方式**：下载后直接运行 EXE，支持 Windows 10/11 x64，无需安装 Python、Node.js 或另行部署前端。新版界面使用微软 WebView2；缺少该组件时，首次启动会询问是否安装，安装过程需要联网。

本版用于魔兽 3.0，沿用已有游戏适配范围。
