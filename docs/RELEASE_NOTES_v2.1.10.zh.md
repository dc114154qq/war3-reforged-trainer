# 魔兽 3.0 修改器 2.1.10

遇到“背包装备未定义”的战役，现在可以用修改器生成一份补齐定义的副本；全被动和全光环也增加了逐项跳过失败技能的处理。

## 本次更新

- **补齐战役／地图背包定义**：在“3.0 扩展”的“读取扩展状态”下方新增按钮。选择 w3n 战役或 w3x 地图，即可生成新副本，原文件保留。
- 处理战役内的全部章节，补入背包、装备、相关天赋及依赖定义，保留原有记录；同编号冲突会明确提示。写入后重新打开文件逐项校验。
- 完整输出路径支持换行、滚动和选中复制，提供“复制输出路径”和“打开输出文件夹”。
- **全被动／全光环继续处理后续技能**：单项技能被游戏拒绝且执行清理已确认时，记录并跳过这一项，继续其余技能；显示完成、跳过数量，并保留详细日志。最高等级设置保持。
- 保留已发布 2.1.09 的批量读取提速、五份游戏适配配置和原有功能。

## 为什么同一战役换个游戏版本就失效

已对照同一份《爱尔兰之魂 1》：3.0.0.24268 加载的技能表包含 3.0 背包定义，3.0.1.24360 这次选中的旧自定义数据表缺少这些定义。判断依据是实际加载的数据，战役制作年代本身不足以判断是否支持。

## 使用方法

点击“补齐战役／地图背包定义” → 选择文件和输出文件夹 → 点击“生成补齐后的副本”。把生成的副本放入游戏对应目录，从该副本重新进入地图；旧存档继续使用原来的地图数据。

适用分区：**魔兽争霸 III 3.0**。内置构建配置：3.0.0.24268、3.0.1.24323、3.0.1.24332、3.0.1.24342、3.0.1.24360。

验证：4,953 项独立离线测试、120 个子测试通过，29 项跳过；EXE 启动自检和包内依赖校验通过。《亡者编年史 1》11 个章节已处理并重新读取校验。处理副本的游戏内背包、装备效果及外机运行尚未验收。
