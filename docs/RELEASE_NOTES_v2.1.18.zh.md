# 魔兽 3.0 修改器 2.1.18

修复部分战役“补齐背包定义”时中途报错的问题，兼容内部文件目录不完整、目录容量较小及残留旧清单的地图；保留本版的背包物品复制、装备位置和原生天赋进度同步等改进。

1. **复制单位带上背包物品**：修正部分地图中技能和物品识别失败导致复制直接报错的问题。除了原有六格物品，也复制 30 格扩展背包的物品，保留原来的格子和空位。复制后检查物品是否实际进入背包，避免物品掉在地上却显示成功。

2. **装备放回对应部位**：主副手、饰品等按原位置复制，两枚戒指分别放到各自槽位，避免第二件挤掉第一件。

3. **同步天赋选择和剩余点数**：复制支持的原生天赋系统中已选择的天赋与未使用点数，修复复制后天赋看起来没有升级的问题。

4. **避免多出背包技能**：物品自带的背包或装备能力随物品恢复，避免再把同一能力当作普通技能重复添加。

5. **修复天赋选择列表**：兼容符合原生天赋结构的自定义背包；选中层级后显示对应选项，添加时核对层级和选择。移除容易误解的“刷新天赋图标”按钮。

6. **结果提示和日志更清楚**：复制后核对物品位置及天赋状态。出现失败或部分完成时弹窗说明具体差异，并提供详细日志路径。

7. **补齐背包定义兼容更多战役**：处理前自动识别地图原有资源的真实路径，再扩充内部目录，解决部分战役刚开始处理就报错的问题。处理后逐项读回核对原内容和新增定义；如有问题，弹窗说明出错章节和具体原因，原文件保留。

复制范围为修改器可读取的物品位置、装备部位、普通技能等级及上述原生天赋状态。战役脚本私有的任务进度、角色专属变量等不属于此次复制范围。

**使用方式**：适用于魔兽 3.0，Windows 10/11 x64。关闭旧版后直接打开 EXE，无需安装 Python、Node.js 或单独启动前端。沿用轻量 WebView2 桌面界面；缺少微软 WebView2 时，首次启动会提示联网安装。

保留鼠标定位、金矿修改、技能和物品字段、套装恢复及其他既有功能。此次修订只涉及离线地图归档处理，游戏适配配置与四个原生组件保持原样。归档和对象表检查通过后才输出；实际游戏效果仍需进入处理后的地图确认。
