# Warcraft III 3.0 Trainer 2.1.14

1. **Updated desktop UI**: a refreshed layout with dark and light themes, clearer text, progress and error dialogs. Full output and log paths can be viewed and copied.
2. **Custom, persistent six-artifact preset**: enter six item codes next to Ctrl+Num3. Valid changes are saved automatically and restored next time. Restore defaults is also available.
3. **Ability fields after Elephant actions**: refreshes the current unit data when reading ability fields, fixing the empty list that previously required restarting the trainer.
4. **Loadout restoration keeps equipped items**: items already placed in the correct equipment slots are preserved. Partial completion and later validation issues report the actual result instead of removing completed equipment.
5. **Backpack definition repair**: fixes legacy campaigns filtering new definitions, crashes while loading processed campaigns, and the incorrect owner-mismatch message after a backpack was added. Reprocess previously affected maps or campaigns with this version and enter from the generated copy's chapter menu. Existing saved games retain their saved data.

**Run**: download and launch the EXE on Windows 10/11 x64. No Python, Node.js or separate frontend setup is needed. The desktop uses Microsoft WebView2. If it is missing, first launch offers to install it; this initial installation requires Internet access.

For Warcraft III 3.0. Existing bundled game-build support is retained.
